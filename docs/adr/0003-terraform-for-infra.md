# 3. Terraform for all AWS infrastructure

## Status
Accepted

## Context
The app needs a VPC, RDS, ECS Fargate, an ALB, S3+CloudFront, and Secrets
Manager entries. Clicking these together in the console is not reproducible
and leaves no diff-able record of change.

## Decision
Define everything under `infra/` as Terraform, split into reusable modules
(`network`, `database`, `ecs`, `frontend`) composed per environment under
`infra/environments/<env>`. State is kept in an S3 backend (bucket referenced
in `environments/dev/main.tf`, created out-of-band before first `init`).

## Consequences
- `terraform plan` gives a reviewable diff before any infra change ships.
- Adding a second environment (staging/prod) is a new `environments/<name>`
  directory reusing the same modules, not copy-pasted resources.
- Secrets (DB password, JWT secret) are generated by Terraform and stored in
  Secrets Manager, never committed or passed as plain environment variables
  in CI.
